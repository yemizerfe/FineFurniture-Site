Forward any API request.

Send a target url, a method, the headers and a body. The proxy performs the request from the edge and hands back the upstream status, headers and body as JSON — or streams it verbatim.

Request payload

{
  "url": "https://api.example.com/v1/items",
  "method": "POST",
  "headers": {
    "authorization": "Bearer TOKEN",
    "content-type": "application/json"
  },
  "body": { "name": "widget" },
  "timeout_ms": 10000,
  "follow_redirects": true,
  "passthrough": false
}
// response
{
  "data": {
    "request": { "url": "…", "method": "POST", "headers": {}, "body_bytes": 21 },
    "response": {
      "status": 201,
      "ok": true,
      "headers": { "content-type": "application/json" },
      "body_encoding": "json",
      "body": { "id": 42 },
      "bytes": 15,
      "truncated": false,
      "duration_ms": 84
    }
  }
}

curl

curl -X POST "/api/proxy" \
  -H "content-type: application/json" \
  -d '{
    "url": "https://api.github.com/repos/cloudflare/workers-sdk",
    "method": "GET",
    "headers": { "accept": "application/vnd.github+json" }
  }'

# GET shorthand, with a custom header
curl "/api/proxy?url=https%3A%2F%2Fexample.com&header.x-test=1"

# stream the upstream response instead of wrapping it
curl -X POST "/api/proxy" \
  -H "content-type: application/json" \
  -d '{"url": "https://httpbin.org/json", "passthrough": true}'

Limits and guardrails

  • Methods: GET, POST, PUT, PATCH, DELETE, HEAD, OPTIONS. GET/HEAD cannot carry a body.
  • Size: request bodies up to 512 KB, upstream responses capped at 2 MB (marked truncated).
  • Time: timeout_ms between 1 000 and 25 000 ms; a slow upstream returns 504 upstream_timeout.
  • SSRF: private, loopback, link-local and metadata addresses (127.0.0.1, 10/8, 169.254.169.254, *.internal, ::1) are refused with 403 blocked_target.
  • Headers: only what you send is forwarded. Hop-by-hop headers and host are recomputed; credentials in the URL are rejected.
  • Encoding: JSON and text come back decoded (body_encoding: "json" or "utf8"); binary comes back as base64.
Note: this endpoint is open, so anyone with the link can proxy through it. Keep the response limits in place, or put an access token in front of it before using it for private APIs.
